# Duck Desk 0.1.0-alpha.10

## Highlights

- Rebuilt the Apple silicon DMG with a valid ad-hoc app signature.
- Fixed the broken app-bundle resource seal that could make macOS Tahoe report "Duck Desk is damaged and can't be opened."
- Added the Electron arm64 library-validation entitlement required for hardened-runtime ad-hoc builds.
- Clarified release copy: the Mac build is ad-hoc signed, not Apple Developer ID signed or notarized.

## Validation

- `npm run mac:dmg`
- `codesign --verify --deep --strict --verbose=4 "/Volumes/Duck Desk 0.1.0-alpha.10-arm64/Duck Desk.app"`
