# Duck Desk 0.1.0-alpha.9

## Highlights

- Fixed live status refreshes overwriting the Stream Title while a creator is typing.
- Fixed live status refreshes overwriting Promo Banners while a creator is typing.
- Moved Stream Title and Promo Banners into one Live Controls messaging panel so show-facing copy is edited in one place.
- Kept Setup focused on OBS connection details instead of mixing connection and show text controls.
- Fixed the Live tab row jumping to the top-right when opening Stream Preview.
