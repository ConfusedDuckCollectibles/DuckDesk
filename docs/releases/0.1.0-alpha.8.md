# Duck Desk 0.1.0-alpha.8

## Highlights

- Added independent Alert Studio toggles for each event type:
  - Banner panel (under-header alert card; Bid ladder for bids)
  - Side pop-out (right-edge BID / SOLD stickers)
- Sale, bid, audience, tip, and share can mix those styles, keep both, or turn both off.
- Existing Alert Studio look controls still apply per event.

## Validation

- `npm run test:alerts`
- `npm run typecheck -w @duck-desk/overlay`
- `npm run typecheck -w @duck-desk/desktop`
- Overlay QA for a sale alert with both the banner card and side pop-out visible.
