# Duck Desk 0.1.0-alpha.11

## Highlights

- Improved live Whatnot purchase detection for text that says a buyer bought, purchased, claimed, or was sold an item.
- Improved live Whatnot bid detection for text such as placed a bid, high bid from, current bid, leading bid, and winning bid.
- Added focused extension parser tests for purchase and bid notification wording.
- Kept the alpha 10 Mac installer signing repair.

## Validation

- `npm run test:extension`
- `npm run typecheck`
- `npm test`
- `npm run build -w @duck-desk/extension`
